A5 Dodecaëder PWA versie 2.0

Bestanden:
- index.html
- manifest.webmanifest
- service-worker.js
- icon.svg, icon-192.png en icon-512.png

Publiceren:
Plaats alle bestanden samen in de hoofdmap van een website die via HTTPS wordt aangeboden, bijvoorbeeld GitHub Pages, Netlify, Vercel of Azure Static Web Apps. Een service worker werkt niet wanneer index.html rechtstreeks als lokaal bestand (file://) wordt geopend.

Installeren:
- Android/Chrome: open de gepubliceerde site en kies Installeer app of Toevoegen aan startscherm.
- iPhone/iPad/Safari: open de site, kies Delen en daarna Zet op beginscherm.

Functies v2.0:
- installeerbare PWA met eigen pictogram
- offline app-shell na het eerste online bezoek
- onthoudt huidige transformatie, invoer en röntgenstand
- print/export via het afdrukvenster (kies daar Opslaan als PDF)
- oefenmodus met willekeurige conjugatieopgaven
